# Manager Library - page (T-23)

Sitio estático de presentación del proyecto: un solo `index.html` con CSS incrustado, sin dependencias ni paso de build. Es responsive (una columna en móvil).

## Cómo verlo
Abre `index.html` en el navegador, o publícalo con GitHub Pages (Settings > Pages > rama `main`, carpeta raíz).

## Cómo se tradujo el spec
La página resume el negocio del spec (plazo de 14 días, último ejemplar, tope de 3 libros, vencidos) y la traducción a Laravel y React.
