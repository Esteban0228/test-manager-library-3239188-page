Qué hace

Catálogo

Registra libros con ISBN válido, categoría y ejemplares. Siempre ves cuántos quedan disponibles.

Socios

Lleva el registro de quién puede pedir prestado, con nombre y documento.

Préstamos

Presta de 1 a 3 libros a la vez, devuelve cada uno por separado y consulta los vencidos.

Reporte

El administrador ve qué libros se prestaron más en un rango de fechas.

Reglas que se respetan

PlazoCada libro se presta por 14 días.
Último ejemplarSi dos personas lo piden a la vez, una recibe el préstamo y la otra un 409. Nunca se presta dos veces.
Tope por socioUn socio no puede tener más de 3 libros prestados.
VencidosUn socio con libros vencidos no puede pedir otro hasta devolverlos.
ErroresToda la API responde los errores con la misma forma: código, mensaje y detalles.

Cómo está hecho

El proyecto sigue Spec-Driven Development: primero el spec y su contrato HTTP, después el código. El spec venía en Python y .NET, y se tradujo a Laravel y React sin cambiar el negocio.

api

Laravel, PostgreSQL y JWT. Reglas de negocio en una capa de dominio pura.

app

React con Vite, servida por nginx.

infra

Un docker compose levanta el motor vacío, la api y la app.

tool

Un sembrador que llena datos de demo usando solo la API.

Cómo ejecutarlo

Solo necesitas Docker. En el repositorio infra:

copy .env.example .env
docker compose up --build

Abre http://localhost:3000 e inicia sesión con el administrador definido en .env.
